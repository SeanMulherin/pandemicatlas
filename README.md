# The Pandemic Atlas

An interactive historical explorer for The New York Times U.S. COVID-19 dataset, published at [seanmulherin.github.io/pandemicatlas](https://seanmulherin.github.io/pandemicatlas/).

It visualizes the national timeline and state-level seven-day averages from January 21, 2020 through March 23, 2023. The shared date animation also drives an interactive county choropleth covering all 3,142 mapped U.S. county geometries, and the mobility section explores county and interstate movement patterns.

## Develop

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Build for GitHub Pages

```bash
npm run build:github
```

The verified contents of `dist-github` are published from the repository's `gh-pages` branch. The deployed site is static and has no ChatGPT Sites or runtime API dependency.

## Validate

```bash
npm test
```

The site includes local snapshots of the Times's national, state, and county rolling-average data plus mobility data under `public/data`, so the explorer does not depend on a live third-party request. County values are shipped in a compact binary matrix with map metadata generated by `analysis/prepare_county_incidence.mjs`. Data attribution and interpretation caveats are shown in the experience.
